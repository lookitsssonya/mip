# ADR 0003: Секреты через переменные окружения

## Статус

Принято.

## Контекст

Сервис использует API-ключ OpenAI для вызова внешнего провайдера.
Если ключ попадёт в репозиторий:

- он будет скомпрометирован (история Git не удаляется);
- его придётся ротировать;
- возможны финансовые потери (злоумышленник использует ключ);
- нарушаются требования безопасности (OWASP, ISO 27001).

## Решение

Хранить секреты **только** в переменных окружения.
В `application.yml` использовать плейсхолдеры:

```yaml
llm:
  providers:
    openai:
      api-key: ${OPENAI_API_KEY:}
```

- Если переменная задана — Spring подставит её значение.
- Если не задана — подставится пустая строка (дефолт после `:`).

В коде секреты **не хранятся** и **не логируются**.

## Последствия

### Положительные

- **Безопасность** — секреты не попадают в Git.
- **Гибкость** — разные значения для dev/staging/prod без изменения
  кода.
- **Соответствие стандартам** — OWASP, ISO 27001, PCI DSS.
- **Работа в CI/CD** — секреты передаются через secrets-vault
  (GitHub Secrets, GitLab CI Variables, HashiCorp Vault).

### Отрицательные

- **Требуется настройка окружения** — при первом запуске нужно
  задать `OPENAI_API_KEY`.
- **Возможны ошибки** — если переменная не задана, приложение
  запустится, но вызовы OpenAI будут падать.

### Нейтральные

- Документация должна явно указывать, какие переменные требуются
  (см. README.md).

## Альтернативы

- **Spring Cloud Config + Vault** — избыточно для лабораторной.
- **`.env` файл** — требует библиотеки `dotenv`, небезопасен,
  легко закоммитить.
- **Шифрование в `application.yml`** (Jasypt) — сложнее,
  требует мастер-пароль.

## Проверка

Перед коммитом убедись, что секретов нет:

```bash
git grep -i "sk-"        # поиск ключей OpenAI
git grep -i "api-key"    # поиск полей с ключами
```

В `application.yml` должно быть только `${OPENAI_API_KEY:}`.

## Пример запуска

**Linux/macOS:**

```bash
export OPENAI_API_KEY=sk-...
mvn spring-boot:run
```

**Windows CMD:**

```cmd
set OPENAI_API_KEY=sk-...
mvn spring-boot:run
```

**Windows PowerShell:**

```powershell
$env:OPENAI_API_KEY="sk-..."
mvn spring-boot:run
```
